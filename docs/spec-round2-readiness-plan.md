## 2. การค้นพบที่เปลี่ยนดีไซน์ — ต้องแยก "อำนาจ" ออกจาก "พื้นที่"

**เมื่ออ่านข้อ 1.1 กับ 1.2 คู่กัน จะดูเหมือนขัดกัน แต่จริง ๆ ไม่ขัด**

| | อาจารย์ตอบว่า | อ้างอิง |
|---|---|---|
| **ดาวมีสิทธิ์ตัดสินไหม** | **ไม่มี** — พูดถึงได้ต่อเมื่อผ่านการตรวจว่าไม่ถูกชง และเป็นธาตุที่ดวงต้องการ | 1.1 + ช่องที่ติ๊กในตาราง + `Soul` หน้า 3 + `DataSpec` B20 |
| **ดาวควรมีพื้นที่แค่ไหนในรายงาน** | **เท่า ๆ กับหัวข้ออื่น** — ไม่ใช่ประโยคแทรก | 1.2 |

แปลว่าท่านแยกสองเรื่องนี้ออกจากกัน: **ดาวไม่ได้เป็นตัวชี้ขาดคำตอบ แต่ควรมีหัวข้อของตัวเองในรายงาน**

ดีไซน์เดิมที่ผมเสนอไว้ใช้ค่าเดียว (`starAuthority`) **ใช้ไม่ได้** ต้องแยกเป็นสอง:

```
starAuthority  = 'modifier'   // ห้าม override ข้อสรุปโครงสร้างธาตุ  ← ตาม 1.1
starProminence = 'section'    // มีหัวข้อของตัวเองในรายงาน          ← ตาม 1.2
```

**ผลที่ตามมา:** ท่อกรอง 4 ชั้นยังต้องทำเหมือนเดิม (ดาวที่ถูกชงหรือเป็นธาตุให้โทษยังถูกปิดเสียง)
แต่ดาวที่**ผ่านด่าน**ต้องได้พื้นที่เป็นหัวข้อ พร้อมคำอธิบายเชิงการทำงานเต็ม ๆ ไม่ใช่แค่ป้ายกำกับ
→ กระทบโครงรายงาน ([`narrative.ts`](../packages/report/src/narrative.ts) ตอนนี้ยังไม่มี section ของดาวเลย)

## 3. การตีความคำตอบ และเรื่องที่ยังค้าง

### 3.1 · ✅ ข้อ 7.2 "ให้ AI ประมวลผลเป็นหลัก" — ตีความแล้ว

อาจารย์ไม่ได้ติ๊กความถี่ใด ๆ แต่เขียนทับลงไปว่า *"ใช้ AI ร่วมด้วย และให้ AI ประมวลผลเป็นหลัก"*
และที่ข้อ 7.1 ตรงช่อง "มีท่านอื่นร่วมด้วย คือ ___" เขียนว่า *"ใช้ AI ร่วมด้วย"*

> **ข้อสรุป (8 ก.ย. 2026): หมายถึง AI ช่วยอาจารย์ตรวจงาน — ไม่ใช่ให้ AI แทนที่ตัวคำนวณในระบบ**

**เหตุผลที่รองรับ:** ข้อความนี้เขียนอยู่ในหัวข้อ "คิวตรวจงาน" ไม่ใช่หัวข้อสถาปัตยกรรม ·
และข้อ 3 ที่ท่านตอบมาในรอบเดียวกัน ยืนยันแนวทาง rule table (5–8 ข้อ เรียงตามความรุนแรง) ซึ่งตรงข้ามกับการให้ AI คิดประเด็นเอง

**ผลต่อระบบ: ไม่มี** — สถาปัตยกรรมตาม `DataSpec` ยังใช้ได้ทั้งฉบับ
rule engine ยังเป็นผู้คำนวณ · LLM ทำหน้าที่เรียบเรียงเท่านั้น (B0 · B37 · A11 ยังบังคับใช้ตามเดิม)

### 3.2 · ✅ คำว่า "ซินแสตรวจทาน" — ตัดสินแล้ว

หน้าแรกเขียนขายไว้ว่า **"ซินแสตรวจทานแพ็กพรีเมียม"** ([`page.tsx`](../apps/app/app/page.tsx) การ์ดฝั่งองค์กร)
เมื่อกระบวนการตรวจมี AI ช่วย คำกว้าง ๆ แบบนี้เสี่ยงถูกอ่านว่าซินแสตรวจรายงานทุกฉบับด้วยตนเอง

> **ข้อสรุป: ระบุให้ชัดว่าซินแสตรวจอะไร และตรวจเมื่อไร** — ไม่ตัดคำนี้ออก
> เช่น *"ซินแสกำหนดกฎการอ่านและตรวจอนุมัติเกณฑ์ทั้งหมด"* ซึ่งตรงกับความจริงทั้งสองด้าน
> (ท่านเป็นผู้กำหนดกฎและอนุมัติสูตรจริงตามข้อ 5.1 และ 7.1) และยังเก็บจุดขายไว้ได้
>
> ⚠️ **ห้ามใช้ถ้อยคำที่สื่อว่าซินแสอ่านรายงานรายฉบับ** จนกว่าจะมีกระบวนการนั้นจริง → งาน **N-4**

### 3.3 · ยังไม่ได้ของสองอย่าง

| | รออะไร | ผลกระทบ |
|---|---|---|
| **กฎ 15–20 ข้อ** (ข้อ 3) | ได้กรอบแล้ว แต่ยังไม่ได้เนื้อกฎและเงื่อนไข | โครงทำได้ · เนื้อยังว่าง — **ทางแก้: ทีมร่างตัวอย่าง 5–8 ข้อส่งให้ท่านแก้ ตามที่ท่านรับแนวทางนี้ไว้แล้วในข้อ 5.1** |
| **ความถี่และรอบตรวจ** (ข้อ 7.2) | ไม่ได้ตัวเลข | **ยังประเมินกำหนดเสร็จของงานฝั่งเนื้อหาไม่ได้** — ค้างมาสองรอบแล้ว |
